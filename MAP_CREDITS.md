# Bundled map credit

`src/main/resources/covebattle/map/cove_battle.zip` is the **Cove** map from the
PlanetMinecraft project *Minecraft Legacy Console Battle Remastered — Cove*:

https://www.planetminecraft.com/project/minecraft-legacy-console-battle-remastered-cove/

In-world name: "Cove Large+ Remastered". Built for Minecraft 1.20.1 (DataVersion 3465);
1.21.1 upgrades it on first load.

The copy here has the original author's personal data stripped — advancements, statistics,
player data, session lock and raid data — leaving only the world itself.

**If the project's terms do not permit redistribution, the map should be pulled from the jar
and downloaded on demand instead.** `MapInstaller` already isolates this: point it at a
download rather than a classpath resource and nothing else changes.
